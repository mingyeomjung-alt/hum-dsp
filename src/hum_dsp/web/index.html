변환과 채널 처리 안내

처리할 대역이 있으면 44.1kHz 입력을 고정 FIR로 48kHz에 변환해 처리한 뒤 원래 샘플레이트로 돌려놓습니다. 모두 0 dB이면 변환 없이 그대로 둡니다. 출력 채널 수는 유지하며, 자동 음량 보정은 하지 않습니다.

스테레오는 파일 전체 RMS가 더 큰 한 채널에서 얻은 설정을 양쪽에 공통 적용합니다. L+R로 합치지 않으며, 원하는 소리의 보호나 음질 개선을 보장하지 않습니다.

길이를 유지하는 로컬 파일 처리

44.1·48kHz · 모노·스테레오 · PCM16 WAV를 최대 10분·128MiB까지 처리합니다. 실시간 처리가 아니며 파일 길이에 따라 수분이 걸릴 수 있습니다. M4A·MP3·24비트·부동소수점 WAV는 지원하지 않습니다.

처리할 대역이 있으면 44.1kHz는 고정 FIR로 48kHz에 변환해 처리한 뒤 44.1kHz로 돌려놓습니다. 변환의 앞뒤 샘플 참조가 필요한 오프라인 처리이며, 48kHz 입력은 변환하지 않습니다. 모두 0 dB이면 샘플레이트 변환·분석·필터를 건너뛰어 원본 PCM16 값을 유지합니다.

44.1kHz 변환은 처리 시간이 더 길고, 경계·고주파·피크가 달라질 수 있습니다. 샘플 수·샘플레이트·채널 수는 유지하되 음질 개선이나 원하는 저음 보호를 보장하지 않으며 자동 음량 보정은 하지 않습니다.

스테레오는 파일 전체 RMS로 고른 한 채널의 설정을 양쪽에 공통 적용합니다. L+R로 합치지 않으며 조용한 다른 채널에만 있는 잡음은 놓칠 수 있습니다.

입력·결과는 이번 로컬 실행 동안 임시 보관되며 새 긴 WAV·고해상도 WAV·MP3/M4A 작업 시작 또는 처리기 정상 종료 시 정리됩니다. 설정 변경만으로 삭제되지는 않습니다. 강제 종료·전원 중단 시 임시 사본이 남을 수 있으며 보안 삭제를 보장하지 않습니다. 필요한 결과는 먼저 저장하세요.

원본의 비트 깊이와 형식을 유지

44.1·48kHz · 모노·스테레오 · PCM16·PCM24·Float32 WAV를 지원합니다. 최대 10분과 128MiB 중 먼저 닿는 한도까지 처리하므로, 고해상도 스테레오는 10분보다 짧아질 수 있습니다. M4A·MP3는 지원하지 않습니다.

출력도 원본과 같은 샘플레이트·채널 수·샘플 수·PCM/Float 형식입니다. 16비트로 낮추지 않으며 디더링·자동 음량 보정은 하지 않습니다. Float32는 유한한 −1 이상·+1 미만 값만 받습니다. NaN·무한대·+1·범위 밖 값이나 처리 후 피크 초과는 거절하며, 자동으로 잘라내지 않습니다.

변환·재생·보관 안내

처리할 대역이 있으면 44.1kHz는 앞뒤 샘플 참조가 필요한 고정 FIR로 48kHz에 왕복 변환합니다. 경계·고주파·피크가 달라질 수 있고 실시간 처리가 아닙니다. 모두 0 dB이면 변환·분석·필터를 건너뛰어 원본 오디오 데이터 값을 유지합니다. 원본 WAV의 부가 메타데이터 보존은 보장하지 않습니다.

스테레오는 파일 전체 RMS로 고른 한 채널의 설정을 양쪽에 공통 적용합니다. L+R로 합치지 않으며, 다른 채널에만 있는 잡음이나 원하는 저음 보호·음질 개선을 보장하지 않습니다.

PCM24·Float32 재생은 브라우저 지원에 따라 다릅니다. 재생되지 않으면 WAV를 저장해 오디오 편집기에서 확인하세요. 미리듣기용으로 몰래 PCM16 변환하지 않습니다.

입력·결과는 새 긴 WAV·고해상도 WAV·MP3/M4A 작업 시작 또는 처리기 정상 종료 시 정리됩니다. 먼저 필요한 파일을 저장하세요. 강제 종료·전원 중단 시 임시 사본이 남을 수 있으며 보안 삭제를 보장하지 않습니다.

MP3·AAC M4A를 디코딩한 뒤 WAV로 처리

MP3·M4A 파일은 최대 32MiB입니다. 디코딩된 오디오는 44.1/48kHz·모노/스테레오이며 최대 10분과 128MiB 중 먼저 닿는 한도까지 지원합니다. 스테레오는 10분보다 짧아질 수 있습니다. M4A는 AAC만 지원하며 ALAC·여러 트랙·앨범 아트가 있는 파일 등은 거절될 수 있습니다.

결과는 디코딩 원본과 같은 샘플레이트·채널 수·샘플 수의 Float32 WAV입니다. 16비트로 낮추거나 MP3·M4A로 다시 인코딩하지 않습니다. A는 압축 파일 자체가 아닌 디코딩 원본 WAV입니다.

디코딩·0 dB·보관 안내

모두 0 dB이면 디코딩된 WAV의 오디오 데이터 값을 그대로 유지합니다. 압축 파일 바이트 보존이나 압축 전 원음 복원을 뜻하지 않으며, 손실 압축의 열화·지연을 복구하지 않습니다.

PyAV 19.x 디코더가 로컬 환경에 있어야 합니다. 없으면 오류를 안내하고 멈추며 자동 설치하거나 외부 변환 서버로 보내지 않습니다. 디코딩된 값은 유한한 −1 이상·+1 미만이어야 합니다. 코덱에 따른 피크 초과나 처리 후 범위 초과는 거절하며, 자동 클리핑·음량 보정은 하지 않습니다.

44.1kHz는 처리할 대역이 있으면 고정 FIR로 48kHz에 왕복 변환합니다. 스테레오는 파일 전체 RMS로 고른 한 채널의 설정을 양쪽에 공통 적용합니다. 원하는 저음 보호·음질 개선은 보장하지 않습니다.

Float32 WAV 재생은 브라우저 지원에 따라 다릅니다. 재생되지 않으면 저장해 오디오 편집기에서 확인하세요. 미리듣기용 PCM16 사본은 만들지 않습니다.

입력·결과는 새 긴 WAV·고해상도 WAV·MP3/M4A 작업 시작 또는 처리기 정상 종료 시 정리됩니다. 먼저 필요한 파일을 저장하세요. 강제 종료·전원 중단 시 임시 사본이 남을 수 있으며 보안 삭제를 보장하지 않습니다.
