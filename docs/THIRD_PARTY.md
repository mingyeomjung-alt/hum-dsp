# Third-party components

The original Hum DSP source is governed by the repository's evaluation
LICENSE. That license does **not** replace third-party licenses.

The base source installation requires Python 3.12+ and NumPy 2.x. They are
installed separately by the user/package manager and are not vendored in this
source repository. An internal Windows candidate includes a Python/NumPy
runtime, but that binary is **not published**: its bundled-runtime rights and
notices require separate review. The public source release does not establish
binary redistribution clearance or include a portable asset.

PyInstaller is a build-time dependency, not a decoder. Its own license and
bootloader exception apply independently. The evaluation license does not
restrict rights that upstream licenses grant in upstream materials.

PyAV 19.x is optional for source-only MP3/AAC-M4A import. No PyAV/FFmpeg codec
DLLs or audio recordings are included in the source repository. The user must
review the actual installed decoder and codec
build's terms and any applicable patent obligations. No blanket commercial
codec-rights clearance is claimed.

Official upstream references:

- [Python license](https://docs.python.org/3/license.html)
- [NumPy license](https://github.com/numpy/numpy/blob/main/LICENSE.txt)

The built-in examples are generated by the project's mathematical signal
functions. Private recordings, third-party sample audio and datasets are not
redistributed in this repository.
